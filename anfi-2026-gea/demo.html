Demo: watch adaptive drift in a real simulated cohort

150 simulated students took a two-stage Python OOP assessment. Each was given an intended skill profile, wrote answers to match it, and the same model then scored those answers. Everything below is read from that run.

Data: simulation/data/simulation_results.jsonl (Sonnet 4.6) and simulation_results_haiku.jsonl (Haiku 4.5) from the adaptive-conversational-assessment project; Stage 1 questions from simulation_questions.json. "Intended" is the mean of the student's true skill values over the skills each assignment tested. "Scored" is the assignment score the system used for routing. Here the misrouted share compares scored against intended, which is not the archetype-based measure in the paper's threshold table.
